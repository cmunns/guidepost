Accessible product tours built on native browser primitives. No positioning
library. No portals. No fighting with z-index, and no hand-rolled focus trap.

**MIT licensed.** 9.7 kB minified + gzipped, stylesheet included. Zero runtime
dependencies.

```bash
npm install @cmunns/guidepost
```

```js
import { Tour } from '@cmunns/guidepost';

const tour = new Tour({
  id: 'onboarding',
  steps: [
    { title: 'Welcome', text: 'A quick tour.', placement: 'center' },
    { target: '#sidebar', title: 'Navigation', text: 'Everything lives here.', placement: 'right-start' },
    { target: '#search', title: 'Try it', text: 'Type to continue.', focus: 'target',
      advanceOn: { event: 'input', when: (e) => e.target.value.length > 2 } },
  ],
});

tour.start();
```

Every example in these docs runs live at [the live demo](https://guidepost.live).

## What it's built on

<CardGrid>
  <Card title="Popover API" icon="rocket">
    The card lives in the top layer, so you're never portaling it somewhere
    else, escalating z-index, or trying to escape `overflow: hidden`.
  </Card>
  <Card title="CSS anchor positioning" icon="setting">
    The browser keeps the card stuck to its target. Browsers that don't have it
    yet get a measured JS fallback.
  </Card>
  <Card title="clip-path spotlight" icon="star">
    One element, and you get a click-through hole for free, so the user can
    actually do the thing the step is talking about.
  </Card>
  <Card title="inert" icon="approve-check">
    The platform handles the focus trap. Everything else is untabbable,
    unclickable, and invisible to screen readers. No keydown interception, no
    sentinel nodes.
  </Card>
</CardGrid>
